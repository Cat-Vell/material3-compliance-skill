# Material 3 System Map

This compatibility entry point replaces the former encyclopedic reference. Load the canonical owner for the task:

- [Foundations and styles](foundations-and-styles.md): tokens, theme, color, typography, shape, elevation, motion.
- [Interaction and accessibility](interaction-and-accessibility.md): state, names, semantics, focus, forms, content, recovery.
- [Component catalog](component-catalog.md): jobs, variants, cross-platform mappings, source and recipe IDs.
- [Layout and responsive](layout-and-responsive.md): window context, canonical layouts, continuity, insets, IME, foldables.
- [Navigation patterns](navigation-patterns.md): IA, bar/rail/drawer/tabs, back, deep links.
- [Source registry](source-registry.md): official URLs, platform support, verification dates.

Material 3 work remains token-first, semantic, accessible, adaptive, and evidence-based. M3 Expressive may amplify color, typography, shape, motion, and component behavior only for a named usability or emotional goal. It never relaxes accessibility, hierarchy, support, or API-verification requirements.
