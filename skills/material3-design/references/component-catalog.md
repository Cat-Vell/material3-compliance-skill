# Material 3 Component Catalog

Canonical semantics and support map. Read the relevant platform recipe for code. Status: `S` supported/stable, `V` verify-current, `F` accessible custom fallback, `R` refuse parity claim. Every record was last verified **2026-07-22**.

## Catalog contract

Required states list only the state classes that must be designed/tested in addition to enabled. All interactive entries also require disabled when disablement exists, focus, pressed, and hover on pointer platforms. “A11y” includes localized name, role/state/value semantics, logical focus, keyboard behavior, and usable touch/pointer target; each row adds component-specific needs.

## Selection gates

Before using a record: state the user job, emphasis, scope, commit model, state set, accessible name, and window/input context. Custom components preserve token consumption, semantics, focus, keyboard, targets, and state behavior. Volatile mappings must be checked against [source-registry.md](source-registry.md); an entry marked `V` is never a promise that the symbol exists in the user's dependency baseline.
